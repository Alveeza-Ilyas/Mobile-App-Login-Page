# Mobile-App-Login-SignUp-Page (Android Login Screen UI)

A modern, responsive, and clean Login-SignUp Screen UI built for Android applications. Designed in **Android Studio** using **Java** and **XML**, this project follows Google's **Material Design** guidelines to deliver a seamless user experience.

---

## Features

* **Material Design Inputs:** Uses `TextInputLayout` and `TextInputEditText` for smooth floating hints and focused states.
* **Password Toggle:** Built-in end icon (`password_toggle`) to show/hide passwords easily.
* **Social Authentication Layout:** Custom-styled circular `CardView` components for Google and Facebook login buttons.
* **Responsive Layout:** Structured with `RelativeLayout` to ensure consistent alignment across different screen sizes.
* **Clean UI Aesthetics:** Features custom elevation, rounded corners, and proper spacing.

---

## Tech Stack & Dependencies

* **Language:** Java / XML
* **IDE:** Android Studio
* **UI Components:**
  * [Google Material Components](https://github.com/material-components/material-components-android)
  * `androidx.cardview.widget.CardView`
  * `de.hdodenhof.circleimageview.CircleImageView`

## How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Alveeza-Ilyas/Mobile-App-Login-SignUp-Page
2. Open **Android Studio**.
3. Select **Open an Existing Project** and navigate to the cloned directory.
4. Sync the Gradle files and press **Run** `(Shift + F10)` on an emulator or physical device.
